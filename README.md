# 🌍 Global Happiness Analytics Dashboard

## 📌 Overview

The Global Happiness Analytics Dashboard is an interactive data visualization project developed using Microsoft Power BI. It explores global happiness indicators and their relationships with economic and social factors across countries and years.

The dashboard provides interactive visualizations to analyze happiness scores, compare countries, and explore factors such as GDP per capita, healthy life expectancy, and freedom.

## 🎯 Objectives

- Analyze happiness scores across countries.
- Compare happiness levels between countries.
- Explore the relationship between happiness and GDP per capita.
- Analyze healthy life expectancy and freedom indicators.
- Explore happiness data across different years.
- Build an interactive dashboard for data exploration.
